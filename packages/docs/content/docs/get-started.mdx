## Install the extension

<Steps>
  <Step>
    ### Open the official listing

    Install Noir Wallet from the [Chrome Web Store](https://chromewebstore.google.com/detail/noir-wallet/mfoghjbpfanobmnoemoepenjjcmfpmdn).

  </Step>
  <Step>
    ### Check the publisher and extension

    Confirm that the listing is Noir Wallet and that the extension ID is `mfoghjbpfanobmnoemoepenjjcmfpmdn`.

  </Step>
  <Step>
    ### Pin Noir Wallet

    Open Chrome's extensions menu and pin Noir Wallet so it stays available in the toolbar.

  </Step>
</Steps>

<Callout type="warn" title="Avoid unofficial downloads">
  Do not install wallet packages sent through direct messages or download an unpacked extension from
  an unknown source.
</Callout>

## Create a new wallet

<Steps>
  <Step>
    ### Choose **Create Wallet**

    Set a strong local password. This password encrypts wallet data on this device.

  </Step>
  <Step>
    ### Record the recovery phrase

    Write the words down in order and keep the backup offline. Do not store it in chat, email, screenshots, or cloud notes.

  </Step>
  <Step>
    ### Confirm the backup

    Complete the recovery phrase check, then wait for the wallet to initialize and sync.

  </Step>
</Steps>

## Restore an existing wallet

Choose **Import wallet** and enter the recovery phrase in the original order. If it has previously received ZEC, choose **Restore Zcash history** and select the approximate first ZEC transaction date or a birthday block height. Then create a local password. Restoring can take time because the wallet must scan Zcash history.
