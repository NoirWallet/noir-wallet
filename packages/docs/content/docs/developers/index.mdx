The Noir Wallet SDK wraps the provider injected at `window.noirwallet` and exposes a typed Zcash API.

## Choose an extension build

<Cards>
  <Card
    title="Mainnet — Chrome Web Store"
    href="https://chromewebstore.google.com/detail/noir-wallet/mfoghjbpfanobmnoemoepenjjcmfpmdn"
    icon="Chrome"
  >
    Install the production extension for real ZEC.
  </Card>
  <Card title="Testnet — GitHub Releases" href="https://zknoir.com/beta/versions" icon="Download">
    Download the official asset whose filename ends with `-testnet.zip`.
  </Card>
</Cards>

<Callout type="info" title="Mainnet and testnet are separate extensions">
  The SDK does not switch networks at runtime. Install the build for the network you are testing;
  each build has a different extension ID and isolated wallet data. See the [installation
  steps](/noir-sdk-integration#install-the-extension).
</Callout>

## Package

```bash title="Install with pnpm"
pnpm add @noir-wallet/sdk
```

The public entry point is `getNoirWallet()`. It returns `null` when the provider is not available.
