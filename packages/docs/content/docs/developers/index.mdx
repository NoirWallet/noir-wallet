The Noir Wallet SDK wraps the provider injected at `window.noirwallet` and exposes a typed Zcash API.

## Install the extension

<Cards>
  <Card
    title="Chrome Web Store"
    href="https://chromewebstore.google.com/detail/noir-wallet/mfoghjbpfanobmnoemoepenjjcmfpmdn"
    icon="Chrome"
  >
    Install the currently published wallet.
  </Card>
  <Card
    title="V2 beta builds"
    href="https://github.com/NoirWallet/noir-wallet/blob/v2/docs/release-workflow.md#routine-previews"
    icon="Download"
  >
    Find the reviewed Beta artifact and load its ZIP locally.
  </Card>
</Cards>

<Callout type="info" title="Choose a network in the wallet">
  V2 uses one extension with a global Mainnet/Testnet Mode in Developer Settings. Changing mode
  locks and reloads the wallet. The SDK cannot change this setting. See the [installation
  steps](/noir-sdk-integration#install-the-extension).
</Callout>

## Package

```bash title="Install with pnpm"
pnpm add @noir-wallet/sdk
```

The public entry point is `getNoirWallet()`. It returns `null` when the provider is not available.
