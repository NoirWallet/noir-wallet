## Recovery phrase

The recovery phrase controls the wallet. Keep it offline, private, legible, and protected from loss. Noir Wallet cannot recover it for you.

If a backup reminder appears, select **Back up** for the named wallet. Enter its local password to view the phrase, save it offline, then confirm the two requested words. Viewing or copying the phrase alone does not complete confirmation. Some wallets created by an older flow need this check even when another wallet is selected.

Removing a software wallet, including its last account, requires two words from that wallet's recovery phrase. Hardware wallets have no local recovery phrase and use their hardware removal flow. Wallets imported from individual private keys use their own removal flow.

## Local password

The password encrypts wallet credentials on this browser profile. It is not a replacement for the recovery phrase and does not protect a device that is already compromised while the wallet is unlocked.

If local access data is missing, Noir Wallet may restore access to another healthy wallet after verifying its password and existing credential binding. It retains the damaged wallet entry. If recovery is unavailable, restore that wallet from its recovery phrase; an access-data error does not mean the password was wrong.

## Auto-lock

Configure a suitable auto-lock period in **Settings > General**. Lock the wallet before sharing the computer or leaving it unattended.

## Connected sites

Review dApp authorizations regularly and remove origins you do not recognize or no longer use. Always confirm the origin in the wallet prompt.

## Hardware wallets

Keystone and Ledger Zcash accounts use supported PCZT transaction flows. Zcash message signing and lending identity are unavailable for both. Keystone cannot send from transparent funds or shield them; lending is unavailable for hardware accounts.

V2 includes a Ledger EVM adapter, pending physical-device acceptance. Only enabled chains exported from the connected device are registered. If a signing prompt expires or the network changes, prepare and approve the request again.

When importing existing Ledger accounts, select the chains and connect your device. The wallet requests the required device App automatically; unlock your Ledger or confirm opening the App when prompted on the device. Choose the matching address from the account list. Change the derivation preset or load the next page if the address is missing; **Advanced** accepts a starting device index. Confirm the selected accounts on the device before adding them. An unavailable balance lookup does not prevent importing an account.

## Incident checklist

<Steps>
  <Step>
    ### Suspected malicious site

    Disconnect the site, lock the wallet, and close the browser tab.

  </Step>
  <Step>
    ### Password exposure

    If the recovery phrase is safe, change the local password on a trusted device.

  </Step>
  <Step>
    ### Recovery phrase exposure

    Treat the wallet as compromised. On a trusted environment, create a new wallet and move remaining funds after independently verifying the destination.

  </Step>
</Steps>
