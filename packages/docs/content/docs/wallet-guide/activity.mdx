Activity combines confirmed on-chain history with locally recorded transactions that are still progressing.

| Status          | Meaning                                                                           |
| --------------- | --------------------------------------------------------------------------------- |
| Pending         | The origin transaction or external relay is still being observed                  |
| Relay confirmed | The relay completed, but a destination Zcash transaction still needs confirmation |
| Success         | The operation reached its final expected result                                   |
| Failed          | The tracked operation reported a terminal failure                                 |

## Cross-chain operations

Swaps and lending can involve more than one network. The origin transaction may be complete before the full operation reaches its destination. For a withdrawal, claim, or swap into ZEC, a successful relay can still leave the destination Zcash transaction confirming.

## If progress appears delayed

1. Open the activity detail and copy the transaction hash when available.
2. Check whether the origin transaction exists on-chain.
3. Distinguish a wallet synchronization delay from an external relay delay.
4. Avoid submitting the same action again until you understand the first result.

<Callout type="info">
  The wallet records a Zcash transaction locally after broadcast. Non-critical catch-up
  synchronization can continue in the background.
</Callout>
