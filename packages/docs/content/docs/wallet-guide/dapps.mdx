Web apps can use the provider injected into the page or WalletConnect. An injected-provider connection request can ask you to authorize one or more wallet accounts for that origin.

## Connection permissions

When a site requests access:

1. Check the site origin shown by Noir Wallet.
2. Select only the accounts the site needs.
3. Read every later signing or transaction request independently.

A connection lets the site request authorized account addresses and balances without another prompt. While the wallet is unlocked, it can also request the current account's locally recorded transaction history, including any stored memo. Sending ZEC or signing a message still requires a separate approval.

## Transaction and signing prompts

Never approve from the website alone. Use the Noir Wallet approval window as the source of truth for the requested action, destination, amount, and account.

## WalletConnect

In the mainnet wallet, open **Settings → WalletConnect**. Paste a WalletConnect link from the dApp, or select **Scan** to open the camera in a browser tab and scan a QR code displayed on another device. Review the website, requested access, and account before connecting. An **Unverified** website has not been verified by WalletConnect; check its address yourself.

Each session shares the selected software account. An approved public-identity permission lets the dApp read that account's signing public key without another prompt. Signatures and transactions still require approval in Noir Wallet. Hardware accounts cannot connect through this flow.

Use **Disconnect** beside a connected app on the WalletConnect page to revoke access. Switching accounts or locking the wallet also disconnects these sessions. Reconnect after switching accounts, restarting the browser, or reloading/updating the extension. The injected provider's separate permissions are managed through **Connected dApps**.

## Disconnect a site

Open **Connected dApps** from the wallet/site icon at the top right of Home, then select **Disconnect** beside an origin you no longer use. Locking the wallet and disconnecting a site are different actions.

<Callout type="warn">
  Noir Wallet support will never ask you to paste a recovery phrase into a dApp, support form, or
  direct message.
</Callout>
