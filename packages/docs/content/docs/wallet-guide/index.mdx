## Before moving funds

1. Confirm that wallet synchronization is current.
2. Verify the complete destination address.
3. Check whether the transaction uses transparent or shielded funds.
4. Review the amount, fee, and destination again on the approval screen.

<Callout type="warn">
  Blockchain transactions are irreversible. Noir Wallet cannot cancel a transaction after it is
  broadcast.
</Callout>
