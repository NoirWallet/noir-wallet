# Security Policy

Please report suspected vulnerabilities privately to [support@zknoir.com](mailto:support@zknoir.com). Include the affected version, reproduction steps, and the potential impact. Do not send recovery phrases, private keys, passwords, or wallet exports.

Avoid publishing exploit details in a public issue before the maintainers have had an opportunity to investigate. For general support and privacy requests, use the same contact listed in the [privacy policy](./packages/docs/content/docs/privacy-policy.mdx).
